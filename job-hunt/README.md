# 📒 就活ノート

企業と選考を、ひとつに。

**[▶ 就活ノートを開く](https://koki3190.github.io/trip-planner/job-hunt/)**

## 主な機能

| 機能 | 内容 |
| --- | --- |
| 企業管理 | 企業名・勤務地・給与・福利厚生・メモの追加、編集、削除 |
| 選考管理 | 応募から内定までの選考状況を記録 |
| 面接予定 | 日本時間で次の面接日時を登録・一覧表示 |
| 検索 | 企業名・勤務地検索、選考状況による絞り込み、並び替え |
| バックアップ | JSONファイルの保存・読み込み |

## 使い方

1. アプリを開き、「企業を追加」から情報を入力します。
2. 「編集」で選考状況と面接日を更新します。
3. 「面接スケジュール」で予定を確認します。
4. 「使い方・保存」からバックアップを保存できます。

HTML / CSS / JavaScriptで構成。入力内容はブラウザのlocalStorageに保存され、自動同期はありません。ブラウザのデータ削除に備えてバックアップを保存してください。

初期登録の3社の情報は2026年10月17日時点の参考情報です。現在の募集要項は各社の情報源から確認してください。個人の面接日時は初期登録されていません。

生成AIの支援を受けて作成した学習用の個人制作アプリです。
